# Свадебный сайт — Виолетта & Арсений

Готовый одностраничный сайт с анимациями и RSVP-формой.

## Подключение Telegram в Vercel

В проекте Vercel откройте Settings → Environment Variables и добавьте:

- `TELEGRAM_BOT_TOKEN` — новый токен от @BotFather
- `TELEGRAM_CHAT_ID` — `927609355`

После добавления переменных сделайте Redeploy.

Токен не хранится в файлах сайта и не должен публиковаться в GitHub.
